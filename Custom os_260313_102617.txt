## HOW AN OS IS BUILT FROM SCRATCH

### THE BOOT SEQUENCE

**Step 1: Power On**
- CPU starts executing at a fixed address in ROM
- BIOS/UEFI firmware initializes hardware

**Step 2: Bootloader (512 bytes for BIOS)**
- BIOS loads first 512 bytes from boot device to memory address `0x7c00`
- Last two bytes MUST be `0x55 0xAA` (magic number) or BIOS rejects it
- This is YOUR code — written in Assembly
- No libraries. No OS. Just raw machine instructions.

**Step 3: Your bootloader does:**
- Sets up CPU registers
- Initializes a stack (without stack, no C code possible)
- Switches from 16-bit Real Mode → 32-bit Protected Mode → 64-bit Long Mode
- Loads your kernel into memory
- Jumps to kernel entry point

**Step 4: Your Kernel takes over**
- Has COMPLETE control of the machine
- No printf. No malloc. No nothing. Only what YOU write.
- Must handle: memory management, interrupts, I/O, everything

## TWO PATHS: BIOS vs UEFI

**BIOS (Legacy):**
- Simpler to start with
- 512 byte bootloader at `0x7c00`
- You control everything from byte one
- Older machines

**UEFI (Modern):**
- More complex but more capable
- Boots a PE executable (like Windows .exe format)
- Already in 64-bit mode when you get control
- Has graphics, filesystem access before your OS even starts
- All modern machines
